# Suleyman Can Yilmaz Freelance Website

Static marketing website ready to deploy on Vercel.

## Local preview

Run any static server from this folder, for example:

```bash
npx serve .
```

## Deploy to Vercel

1. Push this folder to a Git repository.
2. Import that repository in Vercel.
3. Framework preset: `Other`.
4. Build command: leave empty.
5. Output directory: `.` (root).
6. Deploy.

## Customize before going live

- Update business copy, rates, and any social/contact links as needed.
